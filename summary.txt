  WHAT THIS PROJECT DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Portfolio.io is a full-stack AI-powered web application that lets users create,
customize, manage, and share professional portfolio websites in minutes. A user
signs up, picks a visual template from 20 distinct design themes, fills in their
details manually (or uploads a resume for AI auto-fill), and gets a live,
shareable portfolio page with custom URL slug support instantly.

Core features:
  ✔  User authentication (signup / login / logout) via JWT + Supabase Auth & 2FA Email OTP
  ✔  Profile view and update (name, password, avatar)
  ✔  20 distinct, production-grade portfolio templates (Neon Dark, Bold Minimal,
     White Elegance, Blueprint Technical, Neo Brutalist, Editorial Gallery,
     Aurora Glass, Cyberpunk Hacker, Retro CRT Console, Sage Botanical,
     Newspaper Chronicles, Constructivist Swiss, 8-Bit Arcade, Tactical HUD,
     Soft Claymorphism, Vaporwave Synth, Minimalist Monolith, Nordic Minimalist Light,
     Terminal Matrix Green, Luxury Gold Velvet)
  ✔  Interactive 3D Cursor Parallax & Scroll Animations (ParallaxTilt, ParallaxScroll, ParallaxBackground)
  ✔  AI-powered resume auto-fill using Google Gemini 3.6 Flash (PDF & DOCX)
  ✔  AI text polishers for profile bios and project summaries ("Polish with AI")
  ✔  Recruiter Chatbot Assistant widget with vector RAG search capabilities (Qdrant)
  ✔  Smart Job Matcher comparisons with detailed audit scorecards
  ✔  Job Description Form Auto-Tailoring & Optimizing
  ✔  Automated Cold Email Pitch & HR Outreach Suite (`ColdEmailGenerator`)
  ✔  Automated HR & Recruiter Email Discovery Engine (`POST /api/ai/find-hr-email`)
  ✔  One-Click PDF Resume print export layout configurations
  ✔  GitHub Activity Heatmap Integration (`GitHubActivity`)
  ✔  Dynamic Section Schemas for achievements, publications, hackathons, open source, volunteering
  ✔  Template Popularity & Like Counter System
  ✔  Custom URL Slugs and Public Portfolio sharing (`/p/:slug`)
  ✔  Create, read, update, and delete portfolios stored in Supabase (PostgreSQL)
  ✔  Personal dashboard (My Portfolios) showing all user portfolios
  ✔  Template preview with sample data before committing
  ✔  Protected routes — all dashboard/portfolio pages require login

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Frontend  : React (Vite), React Router v7, Framer Motion, GSAP, Tailwind CSS, Lucide Icons
  Backend   : Node.js, Express.js (ES Modules)
  Database  : Supabase (PostgreSQL) — used for portfolio data storage
  Vector DB : Qdrant (Semantic similarity search / RAG context storage)
  Auth      : Supabase Auth (admin SDK) + custom JWT (jsonwebtoken) + 2FA Email OTP
  AI        : Google Gemini 3.6 Flash via @google/genai & LangChain
  File Parse: multer (upload), pdf-parse v2 (PDF), mammoth (DOCX)

  Frontend runs on : http://localhost:5173
  Backend runs on  : http://localhost:5000
